# Beyond Adventures & Growth™

Static website review prepared October 6, 2026, from the approved review site.

## Preview

Run `python -m http.server 8000` from this folder and open http://localhost:8000.
The website does not need an npm build. Publish this folder as the static site root.

## Included

Homepage, service explanations, founder story and team, searchable NJ resource directory, free PDF organizer, and informational Get Support, Insurance & Payment, and Join Our Team pages.

## Still in development

Client authentication, secure clinical intake, employment applications, subscriptions, and payments are not implemented. This static website is not a clinical record system. No insurance participation is confirmed on the insurance page.

The review pages currently request no search-engine indexing. Review that setting before the public launch. Publishing these files to GitHub does not configure domain DNS or hosting automatically.

## History and assets

Prepared on a separate review branch, preserving the original main branch and its history. User-provided photos and approved brand assets are included. Lucide icon licensing is in `05_BRAND_ASSETS/LUCIDE-LICENSE.txt`.
